# Yang et al. (2026): Image + IMU attitude with attention (digital twin)

**Citation:** Yang, X., Wang, H., Zhang, R., Sun, S., & Zhang, M. (2026). A deep
learning method for spatiotemporal significant wave height estimation with ship
attitude compensation. *Ocean Engineering*, 352, 124517.
https://doi.org/10.1016/j.oceaneng.2026.124517 · key `Yang2026`

**Verification:** V2 (abstract); details V3.

## Setup
Shipborne camera and vessel IMU in a **Unity/Crest digital twin**. 47 sea
states × 100 samples (~4,700 image–attitude pairs) at 2 Hz. Virtual buoys give
labels by zero-upcrossing and spectral analysis (agreement < 0.05 m, averaged).
H_s mostly ≤ 2.5 m. The abstract reports robustness on unseen states and seas
above 2 m.

## Method
Pinhole camera with R = R_z(yaw) R_y(pitch) R_x(roll). Attitude encoded as
(sin, cos) of roll, pitch, yaw → MLP. ResNet-18 per frame. Fusion → sinusoidal
positional encoding → multi-head self-attention → temporal mean pooling → MLP
→ H_s. MSE loss. Sliding-window inference with averaging of overlapping windows.

## Results (V3, simulation)
MAE 0.025 m, RMSE 0.032 m, R² 0.994. Ablation: image only (RMSE 0.098) <
+attitude (0.073) < sequence GRU (0.055) / TCN (0.049) < sequence + attitude
GRU (0.051) < **attention fusion (0.032)**. 7–9 frames give a good accuracy /
latency trade-off.

## Limitations
All results are in simulation, and rendering and wave physics define the task.
The authors name the lack of real synchronised shipborne camera–IMU–SWH data as
the key limitation.

## Consequences for Wave_Analysis
- Platform motion is a confound for any moving camera, NDBC buoycams included.
- Dual labelling (time-domain and spectral from one record) is implementable
  with CDIP displacement data (`physics.timeseries`,
  `physics.spectra_models.simulate_surface_elevation` for virtual-buoy tests).
- Reference implementation: `models/multimodal/yang2026.py`.
