# Kim, Cho & Lee (2023): Monoscopic video with ADCP ground truth

**Citation:** Kim, Y.-H., Cho, S., & Lee, P.-S. (2023). Wave height classification
via deep learning using monoscopic ocean videos. *Ocean Engineering*, 288,
116002. https://doi.org/10.1016/j.oceaneng.2023.116002 · key `Kim2023`
(preprint: SSRN 4349127)

**Verification:** V2 (abstract); details V3.

## Setup
Fixed monoscopic camera on a wave-energy converter (Jeju, SW Korea). Nortek
**AWAC ADCP** on the seafloor (~18 m) as the physical reference. Collection
07:00–11:00, grayscale, frames every 0.5 s, fog/rain/ship frames removed.
Five classes of average wave height, 0.75–3.25 m in 0.5 m bins, dominated by
1.25–1.75 m.

## Method
(a) Snapshot CNN: 4 blocks, 16-32-64-64. (b) GoogLeNet features → BiLSTM (2,000
hidden) → dropout 0.5 → FC. Sequence lengths 6–300 s; augmentation by cropping
for the sparse class.

## Results (V3)
Snapshot 0.783 → 180-s video 0.904 → with augmentation 0.932
(precision = recall = accuracy). Errors concentrate in neighbouring classes;
intermediate classes are hardest for snapshots.

## Limitations
Single site, daytime only, filtered weather, class imbalance. The publisher
data-availability statement ("No data was used…") is inconsistent with the
method (V3).

## Consequences for Wave_Analysis
- Temporal context carries information a snapshot lacks. Longer windows mean
  fewer independent samples; that trade-off must be explicit.
- Use ordinal metrics (`evaluation.classification`: within-one accuracy, QWK).
- An ADCP can be a *teacher* for a camera (sensor distillation); NDBC buoy
  ADCPs measure currents, not waves (`docs/datasets/ndbc_adcp.md`).
- Reference implementations: `models/baselines/kim2023.py`.
