# Five full texts for the library check

Record sensor input, target definition, instrument alignment, number of independent sites and dates, split, strongest baseline, and uncertainty from each full text. Review each paper before making priority or improvement claims.

| Paper | What to extract |
|---|---|
| [Y. Liu, G. Xu et al. · spectral image representations](https://doi.org/10.1016/j.oceaneng.2026.127543) | Which physical signal is extracted, what the camera resolves, and how period is validated. |
| [Ahammed & Dang · polarization-aware vision transformer](https://doi.org/10.1016/j.oceaneng.2026.127753) | Whether polarization is measured or inferred and which sea states dominate the height comparison. |
