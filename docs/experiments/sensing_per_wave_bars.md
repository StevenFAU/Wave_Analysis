# Tests 2 and 3 · Instrument-defined shore targets and video comparators

## Test 2 · Does a clip improve mean individual-height classification?

Use CDIP zero-crossing wave times, heights and periods at the paired station. For each clip midpoint or still timestamp, select the containing good historic bulk record and its exact provider time bounds, keeping complete waves in the half-open window. If multiple images share a station/deployment/window, retain its identifier. Keep both Oak Island views together. Report station, camera-to-buoy distance, matched and excluded dates, wave count, flags, and timing offsets. These are incident-sea labels across 6–29 km. File the new table separately from registered bulk or displacement targets.

Compute arithmetic mean individual height, mean of the largest ceil(N/3) and ceil(N/10) individual heights, mean zero-crossing period, and wave count. Require at least 20 complete, finite, positive height/period pairs per window. Recalculate after filtering; preserve denominator and exclusions. Primary quality tier uses provider-evaluated good waves with a good bulk reference. Determine which QC field and flags the provider actually supplies and record its scope before interpreting it. Show unevaluated waves in a separate sensitivity tier, and a comparison to independently derived displacement labels on common windows. When strict coverage is insufficient, record the primary endpoint as unassessable. Never promote flag 2 into the primary cohort.

**Primary endpoint.** Five-class accuracy on measured mean height, in the same half-metre bins and range as Kim (0.75–3.25 m). Compare the frozen whole-clip representation with a frozen midpoint still and the training-fold majority class. Fit equivalent linear classification heads on training dates. Repeat seeds 0, 1, 2; average class probabilities on identical clip IDs. Report RMSE in seconds against training-fold mean for zero-crossing period separately. Fit thresholds/scalers inside each training fold. Group by whole local date, purge shared reference windows across roles, also report equally weighted dates and leave-site-out sensitivity. Choose recipes using only the 18 dates in the committed development list. Freeze all settings before opening later labels. For confirmation train only on development dates and evaluate the later dates once. Report distinct unseen dates and class counts.

**Pass.** Both accuracy(clip) − accuracy(training-fold majority) and accuracy(clip) − accuracy(still) must have paired 95% lower endpoints above zero (2,000 whole-date bootstrap draws, seed 0). Report each delta and all misses. A missing class or single evaluable date is a coverage limitation.
