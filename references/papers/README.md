# Paper PDFs (local only)

Copyrighted PDFs must **not** be committed (`*.pdf` here is git-ignored).
Store your own copies locally under this directory using BibTeX keys as file
names (e.g. `Choi2020.pdf`) so that notes and code can refer to them.

Structured notes and verification status: `docs/literature/papers/` and
`docs/literature/source_verification.md`. Citations:
`docs/literature/bibliography.bib`.

Open-access sources: Kamagata et al. (2026) at <https://arxiv.org/abs/2607.11998>;
Yin et al. (2025) at <https://doi.org/10.1038/s41597-025-06005-5>.
